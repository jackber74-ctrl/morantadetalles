# Moranta Detalles

Web de Moranta: regalos y detalles personalizados.

- `index.html`: la web completa (HTML, estilos y código en un solo archivo).
- `img/`: fotos de productos.
- `netlify.toml`: configuración para publicar en Netlify (sitio estático, sin compilación).

Para cambiar productos, edita el bloque `<script type="application/json" id="productos">` de `index.html`.
